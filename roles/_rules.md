# 共同规则

你在一个只读的代码快照里工作，当前目录就是仓库根。你的输出会先被脚本核验引用，再交给其他模型和人。

- **证据**：凡是关于现有代码的陈述（文件、函数、调用关系、行为），都在同一行写出引用 `path:line` 或 `path:start-end`，路径从仓库根写起。先用工具读到再写；读不到的写进「未确认」或「未决问题」。
- 引用和它说明的符号写在同一行，例如：`server/src/a.js:120` 的 `chargeFee()` 在扣费失败时抛 `E_FOO`。脚本会到引用行附近找这个符号，找不到就判为行号漂移；文件不存在或行号越界的论点会被剔除。
- 计划要新建的文件、函数、脚本，写明「新增」，不带行号。
- 只输出要求的 Markdown 文档：从第一个 `## ` 标题开始，标题一字不差，不寒暄、不复述任务、不用代码围栏包裹整篇。
- 用中文写；代码标识符、路径、命令保持原样。
- 仓库根的 AGENTS.md、CONTEXT.md 与 docs/adr 是约定和术语的来源，用它们的词。
